# Findash / اختاپوس — Obsidian Knowledge Vault

این vault خروجی دانش و روند توسعهٔ اپلیکیشن Findash است و برای بازکردن مستقیم در Obsidian آماده شده است.

## شروع مطالعه

- [[overview]] — خلاصهٔ معماری و وضعیت محصول
- [[index]] — فهرست entityها و conceptها
- [[log]] — تاریخچهٔ ثبت‌شدهٔ تغییرات و تصمیم‌های توسعه
- [[schema]] — قرارداد ساخت و نگهداری دانش
- [[development/development-log]] — timeline کامل توسعه
- [[development/issues-and-roadmap]] — وضعیت issueها و roadmap
- [[assets/asset-catalog]] — رسانه‌های مرتبط با روند طراحی داشبورد

## ساختار

- `entities/` — backend، frontend، data layer، orchestrator و قابلیت دارایی‌ها
- `concepts/` — flowها، تصمیم‌ها، auth، pipeline و گزارش‌ها
- `sources/` — runbookها و مستندات اجرایی
- `development/` — log توسعه، roadmap و تاریخچه Git
- `assets/` — تصاویر ارجاع‌شده و catalog رسانه

لینک‌های داخلی با قالب Obsidian مثل `[[entities/backend]]` و `[[concepts/auth-flow]]` حفظ شده‌اند.
