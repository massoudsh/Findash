شروع سریع

با داکر، در سه دستور بالا بیاورید.

۱
ریپازیتوری را کلون کنید
۲
فایل .env را از روی .env.example بسازید و مقادیر خود را وارد کنید
۳
سرویس‌ها را با داکر بالا بیاورید
git clone https://github.com/massoudsh/Findash.git
cd Findash
cp .env.example .env
docker compose -f docker-compose-core.yml up --build -d

فرانت‌اند روی localhost:3003 و بک‌اند روی localhost:8011 در دسترس است.
